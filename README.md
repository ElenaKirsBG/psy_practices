# Психологические практики и техники

Офлайн-приложение (PWA) для iPhone, iPad и компьютера: библиотека психологических практик с поиском по симптомам и темам и раздел готовых алгоритмов психологических сессий.

## Что внутри

- **1900+ практик и техник** из источников:
  - «700 психотерапевтических техник» (сост. О. Хрулёв)
  - «300 упражнений для гештальт-тренинга» (сост. О. Хрулёв)
  - И.Г. Малкина-Пых. «Практикум по телесно-ориентированной психотерапии»
  - Я. Старак, Т. Кей, Дж. Олдхейм. «Техники гештальт-терапии на каждый день»
  - Практики коллег из Telegram (тема «МЕТОДЫ»), «Упражнения для работы со страхами и фобиями», «Динамическая раскрутка»
  - «Антитревожная рабочая тетрадь»
  - Справочники: режимы схема-терапии, алгоритм диагностики ПТСР, схема первичного интервью, частная практика за 5 шагов
- **Поиск по смыслу**: введите симптом — «выгорание», «самоценность», «отношения», «тревога» — и получите практики по теме, связанные темы и совпадения по полному тексту.
- **50 тем и симптомов** с автоматической разметкой.
- **27 алгоритмов сессий**: порядок проведения, готовые фразы, вопросы клиенту с отметками, «зачем это нужно», шаблоны протоколов, контракта, плана безопасности, дневников.
- Избранное, личные заметки к каждой практике, темы оформления, размер текста, резервная копия.
- **Работает без интернета** после первого открытия.

## Как опубликовать на GitHub Pages (пошагово)

1. Зайдите на github.com → кнопка **New** (новый репозиторий).
2. Название: `psy-practices` → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Распакуйте архив и перетащите в окно **всё содержимое папки** (файлы `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `README.md`, `LICENSE`, `.nojekyll` и папки `data`, `fonts`, `icons`).
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
7. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/psy-practices/`.

## Установка на iPhone

1. Откройте адрес сайта в **Safari**.
2. Подождите, пока в правом верхнем углу появится «● офлайн» (библиотека сохранилась на телефон).
3. Нажмите **Поделиться → На экран «Домой»**.
4. Теперь приложение открывается с иконки и работает без интернета.

## Обновление

При замене файлов в репозитории увеличьте версию кэша в `sw.js` (`praktiki-v1` → `praktiki-v2`) и в `app.js` (`CACHE_NAME`), чтобы телефон загрузил новую версию.
