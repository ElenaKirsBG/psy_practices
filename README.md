# Психокабинет — практики и журнал консультаций

Офлайн-приложение (PWA) для iPhone, iPad и компьютера: библиотека психологических практик с поиском по симптомам и темам, алгоритмы сессий и журнал консультаций.

## Возможности

- **1940 практик и техник** с поиском по смыслу: «выгорание», «самоценность», «отношения», «тревога»…
- **50 тем и симптомов** + свои темы. Любую практику можно **дублировать** в другие темы или **перенести** (кнопка «Темы» на странице практики).
- **30 алгоритмов сессий**: порядок, готовые фразы, вопросы с отметками, «зачем», шаблоны.
- **Свои практики и алгоритмы**: создание, редактирование, «Изменить копию» любой встроенной практики/алгоритма.
- **Журнал консультаций**: дата (день недели подставляется автоматически), время, клиент или код, запрос/тема, техники (можно выбрать из библиотеки), заметка. Поиск, фильтр по периоду, история клиента.
- **Оплата и финансы**: стоимость каждой консультации в любой валюте; статусы «Оплачено», «Не оплачено», «Из пакета», «Бесплатно»; карточки клиентов с тарифом (обычный, со скидкой, бесплатный), пакетами сессий и контактами; аналитика поступлений — каждая валюта отдельно, по месяцам и по клиентам; список долгов с напоминанием клиенту в WhatsApp/Telegram; финансовый отчёт в Word/PDF.
- **Отменённые сессии**: отметка «Отменена клиентом» / «Отменена психологом» с причиной, выделяются красным в журнале, карточке клиента, финансах и выгрузках; отмену можно сделать оплачиваемой (поздняя отмена) или списать из пакета.
- **Выгрузка журнала в Word (.docx) или PDF** за период и/или по клиенту — сохранить на устройство или отправить через мессенджеры.
- **Настройки**: тема, цвет акцента, цвет текста, шрифт, размер текста.
- **Архив**: выгрузка и загрузка всех данных (журнал, свои материалы, темы, заметки, избранное, настройки).
- Работает **без интернета** после первого открытия.

## Публикация на GitHub Pages

1. github.com → **New** → имя репозитория, например `psykabinet` → **Create repository**.
2. **uploading an existing file** → перетащите всё содержимое распакованной папки (включая папки `data`, `fonts`, `icons` и файл `.nojekyll`) → **Commit changes**.
3. **Settings → Pages** → Branch: **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты: `https://ВАШ-ЛОГИН.github.io/psykabinet/`.

Если репозиторий от прошлой версии уже есть — загрузите файлы поверх (Add file → Upload files), старые заменятся.

## Установка на iPhone

Safari → адрес сайта → дождаться «● офлайн» → **Поделиться → На экран «Домой»**. На экране появится иконка «Психокабинет».

## Важно

Журнал и свои материалы хранятся только на устройстве. Регулярно делайте **Ещё → Настройки → Выгрузить архив**.

При обновлении файлов увеличьте версию кэша в `sw.js` и `app.js` (`psykab-v4` → `psykab-v5`).
